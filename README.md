# From Policy to Performance: Exploring Generative AI in Higher Education

## Project Overview 
This project aims to investigate how Generative AI policies have evolved and how these changes may be associated with students' academic performance.

Our goal is to identify trends in university GenAI policies by examining differences in how instructors regulate AI usage, and explore potential relationships between these policies and academic performance. 

## Date
We're currently in the process of identifying how easy it is to collect syllabi and the history of students' academic performance. The group is attempting to collect data from UCSD courses to help identify whether collecting this data would be plausible in terms of the time allotted and whether it is achievable. 

## Code
No code has been written yet. The group plans to use code to identify and classify syllabus policies and distinguish among in support or not in support of GenAI use in courses.
